# idea-page workflows

The procedures `idea-page` loads, one per kind of request.

- `create-page.md` - build a new page: resolve the output folder and look,
  absorb the idea, grill it if it arrived raw, then lay out the HTML.
- `update-page.md` - a surgical edit to an existing page, preserving structure
  and metadata and appending an amendment entry.
- `image-generation.md` - fill or update the page's embedded image slots,
  reading the branding files first and following the recorded image lane rather
  than a hardcoded tool.
