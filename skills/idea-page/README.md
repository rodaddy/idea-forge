# idea-page (skill)

Stage 4 of the pipeline: turn a fully-shaped idea into a polished,
self-contained HTML page with artwork, references, links, and tags, in the
user's own colors and chosen look.

- `SKILL.md` - the page contract and its trigger phrases (build the page, idea
  page, make it a page).
- `workflows/` - the step-by-step procedures the skill loads per request.

It resolves the output folder from `idea-forge/USER-CONFIG.md` and reads
`idea-forge/branding/brand.md` before making any artwork. An unshaped idea is a
hard gate: it grills first.
