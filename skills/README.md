# skills

The ONE canonical source of the kit. Six skill folders, each with a `SKILL.md`;
the installer copies these into the host's skills directory, or adapts them
into zips or pasted instructions when the host needs another shape.

- `idea-forge/` - the conductor that knows what stage an idea is in and what
  comes next. At install, `USER-CONFIG.md` and `branding/` land inside it.
- `spitball-session/` - stage 1, listen-first; the AI holds all action.
- `grilling/` and `grill-me/` - stage 2, one-question-at-a-time sharpening.
- `wayfinder/` - stage 3, optional, for a big foggy idea mapped as tickets.
- `idea-page/` - stage 4, builds the self-contained HTML idea page.

Every stage also works standalone; nothing here is mandatory ceremony.
