# spitball-session (skill)

Stage 1 of the pipeline: the user talks an idea out and the AI just listens.
Detail, excitement, or apparent readiness are not authorization to research,
plan, or act; the AI holds until the user clearly changes modes.

- `SKILL.md` - the listen-first contract and its trigger phrases (spit,
  spitball session, brainstorm, thinking out loud, just listen).

Working state auto-saves to the idea's `notes.md` where the runtime has files.
