# wayfinder references

Sub-contracts `wayfinder` loads only when the map calls for them.

- `local-map.md` - the DEFAULT tracker: the whole effort as plain markdown in
  one folder, no git repo or GitHub account required.
- `issue-tracker-github.md` - the optional tracker, for an effort that already
  lives in a GitHub repo and where the user prefers issues; uses `gh`.
- `grilling.md` - the grilling contract, for wayfinder's grilling tickets and
  destination-naming sessions.
- `prototype.md` - how to build a throwaway artifact that answers one question,
  for prototype tickets.
