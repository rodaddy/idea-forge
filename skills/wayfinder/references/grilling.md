# Grilling (reference)

Adapted from `github.com/mattpocock/skills` `productivity/grilling` (MIT). The same contract gates `idea-page` Create (step 3); this copy serves wayfinder's grilling tickets and destination-naming sessions.

Interview the user relentlessly about every aspect of the idea or design until you reach a shared understanding. Walk down each branch of the decision tree, resolving dependencies between decisions one by one. For each question, provide your recommended answer.

Ask the questions **one at a time**, waiting for feedback on each question before continuing. Asking multiple questions at once is bewildering.

If a *fact* can be found by researching the web or reading the user's notes, prior maps, or idea pages, look it up rather than asking. The *decisions* are the user's -- put each one to them and wait for the answer. Never answer your own questions: a grilling session where the agent supplies both sides has failed.

Do not act on the idea until the user confirms a shared understanding has been reached.

## Terminology capture

As terms crystallise during grilling, capture them in the map's Notes -- terminology only, never implementation detail. Challenge terms that conflict with terms already captured; sharpen vague or overloaded ones ("you said 'customer' -- the buyer or the end user?").
