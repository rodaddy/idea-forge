# wayfinder (skill)

Stage 3, optional: for an idea too big and foggy for one sitting. It charts the
way to the destination as a shared map of investigation tickets, then works
them one at a time until the route is clear.

- `SKILL.md` - the wayfinding contract and its trigger phrases (wayfinder,
  chart a map, map this out).
- `references/` - the trackers and sub-contracts the skill loads on demand.
- `LICENSE.upstream` - the MIT license for the Matt Pocock skills this kit
  adapts (`grilling`, `grill-me`, `wayfinder`, `prototype`).
