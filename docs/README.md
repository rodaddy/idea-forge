# docs

The buyer-facing illustrated guide for Idea Forge.

- `HOW-TO.html` - a single self-contained dark-theme page walking through the
  four-stage pipeline and the one install instruction (hand `installer.md` to
  your AI and say "install idea forge"), with troubleshooting recovery.
- `how-to-images/` - the screenshots and artwork that page references.

Open `HOW-TO.html` in any browser; nothing needs to be built or served.
